\begin{abstract}
    Publishing a mobile game to an app store involves a sequence of repetitive, error-prone manual steps: running tests, building and signing release artifacts, managing version numbers, and uploading to the store. This paper presents the design and implementation of a complete continuous integration and continuous deployment (CI/CD) pipeline for a Godot 4 (.NET/C\#) mobile game targeting Android. Using GitHub Actions as the automation platform and Fastlane as the store-deployment tool, the pipeline automates building, testing, signing, versioning, and Play Store delivery. Godot-specific challenges such as headless export requirements and credential management are discussed alongside the solutions adopted. The resulting pipeline reduces the release process to a single commit and serves as a reproducible template for developers shipping Godot games on Android.
\end{abstract}
