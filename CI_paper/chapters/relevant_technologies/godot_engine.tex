\subsection{Godot Engine}
The Godot Engine, or Godot for short, is an open source game development engine \cite{b1}. Built on C++, Godot supports developing games in its custom scripting language GDScript, C\# or a mix of both. It allows for the creation of 2D and 3D video games and additionally provides different renderers (Forward+, mobile and compatibility) depending on the target platform. This paper uses Godot 4 with the .NET integration, which requires a separate .NET export template and enables the use of C\# testing frameworks such as xUnit in the CI pipeline.

The engine can build executables for all common operating systems and has great compatibility for mobile-based touch controls as well as click controls. This paper will focus on building for Android devices, since the pre-existing game is a mobile card game developed in Godot 4. While Godot can build for iOS as well, this is only possible on macOS devices via Xcode. No such restrictions exist for other operating systems.

\subsubsection{Testing in Godot}

For GDScript based projects the standard tool for Unit Testing is Godot Unit Test (GUT) \cite{b2} which is an open source add-on for the Godot Engine. For C\# based projects it is possible to use testing frameworks like xUnit to write tests purely for the C\# code as long as it is sufficiently decoupled from the Godot related code. While unit tests are typically uncommon for indie games, as those are usually short-lived projects, they make more sense for projects with a longer lifetime, e.g. a mobile game which continuously gets updated with new content.
